# MQ2 Gas Sensor Monitoring Dashboard

An interactive single-page web application (`Gas-Sensor-Project.html`) for real-time monitoring and visualization of MQ2 gas sensor readings.

## Features

- **Real-Time Data Display:** Visualizes gas concentration levels (LPG, Smoke, Methane, Hydrogen).
- **Status Indicators:** Provides visual alerts when gas levels breach safety thresholds.
- **Lightweight & Portable:** Standalone HTML/CSS/JS file that runs directly in any modern browser without external server setup.
